# website/stack/

Framework and tooling packages for web hosts in this polyglot template.

| Directory | Role | Framework pairing |
| --- | --- | --- |
| [`eslint/`](eslint/) | Shared ESLint config | all web packages |
| [`next/`](next/) | Next.js App Router host config / TypeScript env | React |
| [`nuxt/`](nuxt/) | Nuxt 3 app scaffold (static-capable) | Vue |

Site content sources live under [`../src/`](../src/) (`css/`, `html/`, `javascript/`, `php/`). Tests live under [`../test/`](../test/).
