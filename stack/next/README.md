# stack/next/

Next.js configuration and TypeScript environment references for a **React** host app generated from this template.

| File | Role |
| --- | --- |
| `next.config.js` | Static export, optional `basePath`, image unoptimized, public env |
| `next-env.d.ts` | Next.js TypeScript references (managed / regenerated by Next CLI) |

## Usage

When scaffolding an App Router package at the repo root (or under `typescript/` / `website/`):

1. Install `next`, `react`, and `react-dom`.
2. Re-export this config from the package root:

```js
// next.config.js (package root)
module.exports = require('./stack/next/next.config.js');
```

3. Point `tsconfig.json` `include` at `stack/next/next-env.d.ts` (or copy a root `next-env.d.ts` that references it).

```bash
npx next dev
npx next build
```

See also: [`../nuxt/`](../nuxt/) for the Vue-oriented host (Nuxt).
